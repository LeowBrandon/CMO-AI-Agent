# CMO AI Prototype

A standalone, interactive prototype based on the CMO AI Agent proposal for startups and SMEs.

## Run
Open `index.html` directly in Chrome/Edge/Firefox. No build step or server is required.

## Included workflows
- Dashboard / Marketing Health Score
- Brand Brain with editable brand context
- AI weekly Content Planner
- Content Studio with seeded marketing assets
- Campaign review and scoring
- Analytics dashboard with AI analysis
- Ask Your CMO conversational demo
- Modal for AI campaign creation
- Human approval flow for assets

## Prototype note
This is a front-end demo. AI outputs and analytics are simulated locally so the core user experience can be demonstrated without API keys. A production version can connect the same screens to an LLM API, database, analytics providers, and automation tools.
